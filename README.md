# QRCodeGeneratorPro - iOS App

Compose Multiplatform (Kotlin + SwiftUI)

## GitHub Secrets Required
- `APPLE_TEAM_ID` - Apple Developer Team ID
- `BUILD_CERTIFICATE_BASE64` - Base64 .p12 certificate
- `P12_PASSWORD` - Certificate password
- `BUILD_PROVISION_PROFILE_BASE64` - Base64 .mobileprovision

## CI
Push to main ¡ú GitHub Actions builds IPA automatically.
